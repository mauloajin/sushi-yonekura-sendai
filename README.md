喫煙条件・総席数は媒体間または公式内の矛盾があるため省略。専用駐車場、ランチ、子供条件、貸切、サービス料、英語メニュー、英語対応、ハラルは明確な最新根拠がないため省略。写真は転載権未確認のため不使用。抽象装飾のみ。口コミ・評価点を事実根拠にしない。
